# おはじきバトル

**▶ ブラウザですぐ遊べます → <https://mass584.github.io/ohajiki-battle/>**

おはじきを弾いて相手のコマを削り、穴に落とす、ターン制の対戦ゲーム。
斜め見下ろしの盤面に 2〜8 人が並び、最後までコマを残したプレイヤーの勝ちです。

**`index.html` 1 ファイルだけで動きます。** 依存パッケージもビルド手順もありません。
画像は 1 枚も持たず、キャラクターも地面もテクスチャも、すべて起動時に Canvas で描いています。
効果音と BGM も Web Audio の合成音です。

## 遊ぶ

<https://mass584.github.io/ohajiki-battle/> を開くだけです。

手元で動かす場合は、`index.html` をダウンロードして

```sh
python3 -m http.server 8731
```

を実行し <http://127.0.0.1:8731/index.html> を開きます。

## 遊びかた

自分のコマを**クリックして選び**、**引っぱって離す**と、引いた向きの逆に飛びます。
引いた距離がそのまま勢いです。壁に当たれば跳ね返り、中央の穴に落ちたコマは即死します
（勢いが強ければ飛び越えます）。

敵に当てると HP を削れますが、**当てた側にも受けた側の半分のダメージ**が入ります。
硬い相手にぶつかるほど反動も大きくなります。味方同士はノーダメージです。

`Esc` で引き絞りを取り消せます（発射せずに構え直せます）。

### 遊びかたは 3 つ

| | 内容 |
|---|---|
| **おまかせ** | 初期設定のまますぐ始める。設定画面を読まずに 2 クリックで試合へ |
| **対戦** | 人数・CPU の強さ・ステージ・自分の陣営を選んで 1 試合。相手の陣営は自動で割り振られます（重複なし） |
| **連戦** | 勝ち抜き方式。1 戦ごとに人数と CPU の強さが上がり、勝つたびに**加護**を 1 つ選べます。コマの HP は次の戦いへ引き継がれ、全滅したら終わり |

### 8 つの陣営

陣営ごとに HP・攻撃・機動が違い、各陣営に 1 体だけいる**隊長**が固有の特殊能力を持ちます。

| 陣営 | 特徴 | 隊長の特殊能力 |
|---|---|---|
| ドワーフ | 一撃が重いが飛ばない | 剛撃（この一撃 攻撃 1.5 倍） |
| エルフ | 軽やかに遠くまで飛ぶが当たりは軽い | 精霊の矢（動かず遠隔 48） |
| オーク | とにかく頑丈だが鈍い | 猛進（速度 1.5 倍・穴を無視） |
| アンデッド | 脆いが素早い | 蘇生（倒れた味方を 1 体復活） |
| ゴブリン | 紙装甲だが誰よりも転がる | 爆弾（着弾点の周囲をまとめて 42） |
| 騎士 | 重装で安定 | 聖盾（次に受ける 70 を肩代わり） |
| 魔道士 | 非力だが小回りがきく | 転移（好きな場所へ瞬間移動） |
| 獣人 | 鋭い爪と俊足だが打たれ弱い | 連撃（このターンもう一度撃てる） |

**色はプレイヤーを表します**（1P 青／2P 赤／3P 黄／4P 緑…）。陣営は駒の姿と紋章で見分けます。

### 8 つのステージ

森の円環／岩窟の六角／氷湖の四角／砂漠の八角／星屑のピンボール／歯車工房／終焉の大渦／渦の回廊。

形（円・多角形・星・歯車・花）、穴の数と位置、床の滑りやすさが違います。
弾き飛ばす**バンパー**や中心への**引力**が乗るステージもあります。
**盤面は試合中いっさい動きません**（壁も穴も止まったまま）。

### 記録

右上の 📜 から、通算成績・**制覇表**（ステージ × 陣営 × CPU の強さ の全 192 マス）・
**実績**・ステージ別の自己ベストを見られます。記録はこの端末のブラウザに保存されます。

## ホーム画面に追加して遊ぶ（PWA）

ストアを通さずに、**アプリのように**インストールできます。追加は無料で、
オフラインでも起動します。

- **iPhone / iPad**: Safari で開き、共有ボタン → 「ホーム画面に追加」
- **Android**: Chrome で開き、メニュー → 「アプリをインストール」
- **PC**: Chrome / Edge のアドレスバー右のインストールアイコン

追加すると、ブラウザの UI が無い全画面で起動し、機内モードでも遊べます。

> **記録の置き場所に注意。** 保存はブラウザごと・オリジンごとです。iOS では
> ホーム画面のアプリと Safari のタブで保存場所が分かれるため、**Safari で遊んだ
> 記録はホーム画面版へは引き継がれません**（追加したあと遊び直すことになります）。
> 逆に、ホーム画面に追加しておくと Safari の保存期限（しばらく開かないと消える）の
> 対象から外れるので、記録は長持ちします。

## ネイティブアプリ（iOS / Android）

この自己完結 HTML を **WebView で包んだネイティブアプリ**をモノレポとして同梱しています。

```
packages/sim/   sim（物理・AI・ルール）を DOM 無しの Node で回すヘッドレス host + 回帰テスト
apps/mobile/    Expo + react-native-webview のネイティブアプリ（ゲーム本体は無改造で同梱）
scripts/        index.html を「自己完結 1 枚 HTML」に畳む inline スクリプト / アイコン生成
index.html      ゲーム本体（Web 版 & Pages のまま。sim の唯一の真実）
manifest.json   PWA の宣言（名前・アイコン・全画面表示）
sw.js           オフライン起動のための Service Worker（キャッシュのみ）
icons/          ホーム画面用アイコン。scripts/icons.mjs が生成する成果物
```

- モバイル: [`apps/mobile/README.md`](apps/mobile/README.md)
- ヘッドレス sim / 回帰テスト: [`packages/sim/README.md`](packages/sim/README.md)（`node packages/sim/test/selfplay.js`）
